# Story 2.3: 출처 조항 표시 및 반응형 디자인

Status: review

## Story

As a 교사,
I want 챗봇 답변 아래에 근거가 된 조항 번호가 구분되어 표시되고, 스마트폰에서도 정상적으로 사용할 수 있는 화면을,
so that 답변의 신뢰성을 바로 확인하고 어디서든 규정을 조회할 수 있다.

## Acceptance Criteria

1. **Given** 챗봇 답변에 `sources` 배열이 포함되어 있을 때 **When** `ChatMessage.tsx`가 답변을 렌더링하면 **Then** 답변 텍스트 아래에 출처 조항(article_number, article_title)이 인용 블록 스타일로 구분되어 표시된다
2. **Given** 출처 조항이 여러 개인 경우 **When** 답변이 표시되면 **Then** 관련된 모든 조항이 나열되어 표시된다
3. **Given** 유사도 임계값 이하로 "규정에 명시되어 있지 않습니다" 답변이 반환된 경우 **When** 해당 메시지가 표시되면 **Then** 출처 조항 없이 안내 메시지만 표시되며 시각적으로 일반 답변과 구분된다
4. **Given** 교사가 PC 브라우저에서 접속했을 때 **When** 채팅 화면이 로드되면 **Then** 넓은 화면에 적합한 레이아웃(최대 너비 제한, 중앙 정렬)으로 표시된다
5. **Given** 교사가 모바일 브라우저에서 접속했을 때 **When** 채팅 화면이 로드되면 **Then** 화면 전체 너비를 활용하며 입력창과 버튼이 손가락으로 조작하기 적합한 크기로 표시된다

**현재 파일 상태 (Story 2.2에서 완성된 코드):**


**목표 구현 (sources 렌더링 + 시각 구분 추가):**
```tsx
import type { ChatMessage } from "@/lib/types";

interface ChatMessageProps {
  message: ChatMessage;
}

export default function ChatMessageComponent({ message }: ChatMessageProps) {
  const isUser = message.role === "user";
  const hasSources = message.role === "assistant" && (message.sources?.length ?? 0) > 0;
  // "규정에 명시되어 있지 않습니다" 답변 = sources 없는 assistant 메시지
  const isNoInfo = message.role === "assistant" && !hasSources;

  return (
    <div className={`flex ${isUser ? "justify-end" : "justify-start"}`}>
      <div
        className={`max-w-[80%] rounded-2xl px-4 py-3 text-sm ${
          isUser
            ? "bg-blue-600 text-white"
            : isNoInfo
            ? "border border-amber-200 bg-amber-50 text-amber-800"
            : "border border-gray-200 bg-white text-gray-800"
        }`}
      >
        <p className="whitespace-pre-wrap">{message.content}</p>

        {hasSources && (
          <div className="mt-2 flex flex-col gap-1 border-t border-gray-100 pt-2">
            {message.sources!.map((src, i) => (
              <div
                key={i}
                className="rounded-lg bg-blue-50 px-3 py-1.5 text-xs text-blue-700"
              >
                {src.article_number && (
                  <span className="font-semibold">{src.article_number}</span>
                )}
                {src.article_number && src.article_title && (
                  <span className="mx-1">·</span>
                )}
                {src.article_title && <span>{src.article_title}</span>}
              </div>
            ))}
          </div>
        )}
      </div>
    </div>
  );
}
```

**핵심 설계 결정:**

1. **isNoInfo 판단 기준:** `sources` 배열이 없거나 비어있는 assistant 메시지 → amber 스타일
   - 백엔드가 관련 조항 없음 판단 시 `{"answer": "...", "sources": []}` 반환 (sources 빈 배열)
   - 이 경우 `hasSources = false` → `isNoInfo = true` → amber 배경 적용

2. **null 안전 처리:** `Source.article_number`와 `Source.article_title`은 모두 `string | null` — 각각 렌더링 전 null 체크 필수

3. **sources key={i}:** sources 배열은 메시지당 고정 순서이며 추가/삭제가 없으므로 index key 허용

4. **`py-2` → `py-3`:** sources 영역이 생기면서 수직 여백을 약간 늘려 가독성 확보

5. **border-t 구분선:** 답변 텍스트와 sources 섹션을 `border-t border-gray-100 pt-2`로 시각적 분리

**보존해야 할 기존 동작:**
- user 메시지: `justify-end`, `bg-blue-600 text-white` 말풍선
- `max-w-[80%]`: 말풍선 최대 너비 제한
- `whitespace-pre-wrap`: 줄바꿈 보존
- `rounded-2xl`: 둥근 말풍선 모양

### `Source` 타입 참조 (types.ts 현재 상태)

```typescript
// types.ts (수정 금지 — 이미 완성된 타입)
export interface Source {
  article_number: string | null;   // null 가능 — 반드시 체크 후 렌더링
  article_title: string | null;    // null 가능 — 반드시 체크 후 렌더링
}

export interface ChatMessage {
  _key?: string;          // client-side only, never sent to backend
  role: ChatRole;
  content: string;
  sources?: Source[];     // assistant 메시지에만 존재 (undefined 또는 빈 배열)
}
```

**중요:** `sources`는 `undefined` 또는 `[]`(빈 배열) 두 경우 모두 존재. `(message.sources?.length ?? 0) > 0`으로 체크.

### 백엔드 응답 케이스별 sources 값

| 상황 | 백엔드 응답 | 프론트엔드 상태 |
|------|------------|----------------|
| 관련 조항 있음 | `"sources": [{"article_number": "제3조", "article_title": "성적이의신청"}]` | `hasSources=true`, 파란 인용 블록 표시 |
| 관련 조항 없음 | `"sources": []` | `hasSources=false`, `isNoInfo=true`, amber 배경 |
| (사용자 메시지) | N/A | `isUser=true`, 파란 말풍선 |
