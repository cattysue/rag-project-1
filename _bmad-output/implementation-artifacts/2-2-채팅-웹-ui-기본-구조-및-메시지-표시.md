# Story 2.2: 채팅 웹 UI — 기본 구조 및 메시지 표시

Status: review

## Story

As a 교사,
I want 링크로 바로 접속하여 "규정이"에게 질문을 입력하고 답변을 대화 형식으로 볼 수 있는 웹 화면을,
so that PDF를 열지 않고도 규정 내용을 빠르게 확인할 수 있다.

## Acceptance Criteria

1. **Given** 교사가 웹 링크로 채팅 페이지에 접속했을 때 **When** 메인 페이지(`/`)가 로드되면 **Then** 챗봇 이름 "규정이"가 표시되고, 대화 내역 영역과 하단 고정 입력창이 보인다
2. **Given** 교사가 질문을 입력하고 전송 버튼을 누르거나 Enter를 누른 경우 **When** API 응답을 기다리는 동안 **Then** 전송 버튼이 비활성화되고 로딩 스피너가 표시되어 처리 중임을 알 수 있다
3. **Given** 챗봇 답변이 도착했을 때 **When** 대화 내역 영역이 업데이트되면 **Then** 교사 질문(오른쪽)과 챗봇 답변(왼쪽)이 말풍선으로 구분되어 표시된다
4. **Given** 대화가 여러 번 이어졌을 때 **When** 새로운 메시지가 추가되면 **Then** 대화 내역이 자동으로 최신 메시지로 스크롤된다
5. **Given** 브라우저 탭이 열려 있는 동안 **When** 교사가 후속 질문을 전송하면 **Then** 이전 대화 내역이 유지된 상태에서 연속 질문·답변이 가능하다 **And** 페이지를 새로고침하면 대화 내역이 초기화된다

```typescript
export async function sendChatMessage(
  question: string,
  messages: { role: string; content: string }[],
  signal?: AbortSignal
): Promise<ChatResponse> {
  const res = await fetch(`${BASE_URL}/chat`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ question, messages }),
    signal,
  });

  if (!res.ok) throw new Error("CHAT_FAILED");
  return res.json();
}
```

### Task 4: ChatInput.tsx 구현 가이드

```tsx
"use client";

import { useState, type FormEvent, type KeyboardEvent } from "react";

interface ChatInputProps {
  onSend: (question: string) => void;
  isLoading: boolean;
}

export default function ChatInput({ onSend, isLoading }: ChatInputProps) {
  const [value, setValue] = useState("");

  const handleSubmit = (e: FormEvent) => {
    e.preventDefault();
    const trimmed = value.trim();
    if (!trimmed || isLoading) return;
    onSend(trimmed);
    setValue("");
  };

  const handleKeyDown = (e: KeyboardEvent<HTMLTextAreaElement>) => {
    // Enter만 전송, Shift+Enter는 줄바꿈
    if (e.key === "Enter" && !e.shiftKey) {
      e.preventDefault();
      const trimmed = value.trim();
      if (!trimmed || isLoading) return;
      onSend(trimmed);
      setValue("");
    }
  };

  return (
    <form onSubmit={handleSubmit} className="flex gap-2 border-t border-gray-200 bg-white p-4">
      <textarea
        value={value}
        onChange={(e) => setValue(e.target.value)}
        onKeyDown={handleKeyDown}
        placeholder="질문을 입력하세요..."
        disabled={isLoading}
        rows={1}
        className="flex-1 resize-none rounded-xl border border-gray-300 px-4 py-2 text-sm focus:outline-none focus:ring-2 focus:ring-blue-500 disabled:opacity-50"
      />
      <button
        type="submit"
        disabled={isLoading || !value.trim()}
        className="flex items-center justify-center rounded-xl bg-blue-600 px-4 py-2 text-sm font-medium text-white transition-colors hover:bg-blue-700 disabled:cursor-not-allowed disabled:opacity-50"
      >
        {isLoading ? (
          <span className="inline-block h-4 w-4 animate-spin rounded-full border-2 border-white border-t-transparent" />
        ) : (
          "전송"
        )}
      </button>
    </form>
  );
}
```

**스피너 패턴:** `border-2 border-white border-t-transparent animate-spin` — FileUpload.tsx의 패턴과 동일하게 통일

### Task 5: ChatWindow.tsx 구현 가이드

```tsx
"use client";

import { useState, useRef, useEffect } from "react";
import ChatMessageComponent from "@/components/chat/ChatMessage";
import ChatInput from "@/components/chat/ChatInput";
import { sendChatMessage } from "@/lib/api";
import type { ChatMessage } from "@/lib/types";

export default function ChatWindow() {
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [isLoading, setIsLoading] = useState(false);
  const bottomRef = useRef<HTMLDivElement>(null);

  // 새 메시지 추가 시 자동 스크롤
  useEffect(() => {
    bottomRef.current?.scrollIntoView({ behavior: "smooth" });
  }, [messages]);

  const handleSend = async (question: string) => {
    // 1. 사용자 메시지 즉시 표시
    const userMessage: ChatMessage = { role: "user", content: question };
    const nextMessages = [...messages, userMessage];
    setMessages(nextMessages);
    setIsLoading(true);

    try {
      // 2. 이전 대화 이력을 백엔드로 전송 (sources 제외, role+content만)
      const history = messages.map(({ role, content }) => ({ role, content }));
      const res = await sendChatMessage(question, history);

      // 3. 챗봇 답변 추가
      const botMessage: ChatMessage = {
        role: "assistant",
        content: res.answer,
        sources: res.sources,
      };
      setMessages((prev) => [...prev, botMessage]);
    } catch {
      // 4. 에러 시 안내 메시지 표시
      const errMessage: ChatMessage = {
        role: "assistant",
        content: "서버에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요.",
      };
      setMessages((prev) => [...prev, errMessage]);
    } finally {
      setIsLoading(false);
    }
  };

  return (
    <div className="flex flex-1 flex-col">
      {/* 대화 내역 영역 */}
      <div className="flex-1 overflow-y-auto px-4 py-6">
        <div className="mx-auto max-w-2xl flex flex-col gap-4">
          {messages.length === 0 && (
            <p className="text-center text-sm text-gray-400">
              규정에 대해 궁금한 점을 질문해 보세요.
            </p>
          )}
          {messages.map((msg, i) => (
            <ChatMessageComponent key={i} message={msg} />
          ))}
          <div ref={bottomRef} />
        </div>
      </div>

      {/* 하단 고정 입력창 */}
      <div className="mx-auto w-full max-w-2xl">
        <ChatInput onSend={handleSend} isLoading={isLoading} />
      </div>
    </div>
  );
}
```

**대화 이력 전송 핵심 로직:**
```typescript
const history = messages.map(({ role, content }) => ({ role, content }));
```
`sources` 필드 제외 — 백엔드 `ChatRequest`가 `role`과 `content`만 기대함.

**messages 상태 업데이트 패턴:**
- 사용자 메시지: `setMessages(nextMessages)` (현재 messages 기반으로 새 배열 생성)
- 봇 응답: `setMessages((prev) => [...prev, botMessage])` (함수형 업데이트 — async 클로저 stale 방지)
