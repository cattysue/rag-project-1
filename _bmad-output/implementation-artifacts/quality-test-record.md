## 판정 기준

- **O (정답)**: 챗봇 출처 조항이 핵심 조항과 일치하거나 동일 조항의 하위 항목인 경우
- **X (오답)**: 완전히 다른 조항이 반환되거나, "규정에 없다"고 했는데 실제 조항이 존재하는 경우
- 검색 품질 기준이므로 **조항을 올바르게 찾았다면 답변 텍스트 품질과 무관하게 O**

## 테스트 질문 목록 및 결과

> 1. Railway 프론트엔드 채팅 화면에서 아래 질문을 순서대로 입력합니다.
> 2. 챗봇 답변의 "출처 조항" 부분(조항 번호)을 "챗봇 출처 조항" 칸에 기록합니다.
